tune Scenario Question • Architectural Redundancy ID: AZ900-D2-Q04

Contoso Retail is planning to deploy a customer-facing e-commerce application on Azure virtual machines. The architectural requirement mandates protection against data center power, cooling, or network failures within an Azure region, with ultra-low latency between redundant application instances without needing to replicate data across different geographical continents.

Which Azure architectural feature should Contoso configure to satisfy this requirement?

lightbulb
Architectural Clue

Pay attention to the scope: “within an Azure region” combined with “independent power, cooling, and networking” while maintaining “ultra-low latency”. Cross-region architectures involve higher network round-trip times and geographic dispersion across hundreds of miles.

check_circle Correct! Availability Zones guarantee localized resilience.

Availability Zones are unique physical data center buildings within an Azure region. Each zone has independent power, cooling, and networking. Because they are connected via high-speed, private fiber-optic networks, synchronous replication and round-trip times stay under 2ms.

Architectural Scope account_tree

Zones represent distinct physical data centers within a single geographic region.
